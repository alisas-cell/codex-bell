# Codex Bell v1.0.1 — 更准确的任务提醒 / More accurate task alerts

2026-09-06

## 中文

### 重点更新

- **主任务完成才提醒。** 修复内部子代理结束时误播主任务「已完成」的问题。
- **出错和重试不再混为成功。** 服务过载、额度不足等错误结束会标记为失败；明确正在重连或重试时，任务继续保持运行。
- **最近完成更简洁。** 可见任务从 5 条减少为 3 条，较早的脱敏历史仍保留在内部。

### 新功能

本次为修复与体验优化版本，无新增独立功能。

### 改进与修复

- 无法确认成功的空结果显示「结果未确认」，不播放完成提示。
- 读取到历史误判记录时安静纠正，不重放旧提示音。
- 已排队但被新任务状态取代的提醒会跳过，避免任务已恢复却听到旧的完成提示。
- 保留子代理过滤、正常完成去重、Dock 默认关闭、左右停靠及隐私脱敏。

### 安装与已知限制

下载下面的 `Codex-Bell-macOS-v1.0.1.zip`，退出旧版 Bell 后解压并替换 `Codex Bell.app`，再重新打开。无需删除设置或重新配置 Codex。

支持 **macOS 14 Sonoma 及以上、Apple silicon（arm64）**。此版本采用 hardened runtime + ad-hoc 签名，**未使用 Apple Developer ID，未经过 Apple 公证**。首次启动如被拦截，可尝试 Control 点击应用后选择「打开」，或使用「系统设置 → 隐私与安全性 → 仍要打开」。也可从源码构建。

Bell 的状态识别依赖本机 Codex 提供的生命周期事件；未来事件格式变化可能需要集成更新。

## English

### Highlights

- **Alerts follow the main task.** Internal subagent turns no longer trigger a misleading “task completed” announcement.
- **Errors and retries stay distinct from success.** Terminal capacity or usage-limit errors are marked as failed. Explicit reconnect/retry states remain running.
- **A smaller Recent list.** Three recent terminal tasks are visible instead of five, with older redacted history retained internally.

### New features

This is a maintenance update focused on fixes and usability, with no new standalone features.

### Improvements and bug fixes

- Empty outcomes without success confirmation show “Result unconfirmed” and do not announce completion.
- Historical misclassifications are corrected silently when read, without replaying old sounds.
- Queued alerts superseded by a newer task state are skipped, preventing an old completion alert after work resumes.
- Subagent filtering, normal completion deduplication, Dock-off defaults, Left/Right docking, and privacy redaction are preserved.

### Installation and known limitations

Download `Codex-Bell-macOS-v1.0.1.zip` below. Quit the previous Bell instance, unzip and replace `Codex Bell.app`, then reopen it. Existing settings and Codex integration can be kept.

Requires **macOS 14 Sonoma or later and Apple silicon (arm64)**. The build uses hardened runtime with an ad-hoc signature. It is **not Apple Developer ID signed and NOT NOTARIZED**. If macOS blocks the first launch, try Control-click → Open, or System Settings → Privacy & Security → Open Anyway. Building from source is also supported.

State detection depends on lifecycle events supplied by the local Codex host. Future format changes may require an integration update.
