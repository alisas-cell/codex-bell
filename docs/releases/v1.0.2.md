# Codex Bell v1.0.2 — 悬停移除任务 / Hover to dismiss tasks

2026-09-25

## 中文

### 重点更新

- **卡住的记录，可以自己清理。** 鼠标移到「正在运行」的任务行，右侧才会显示小 ×，点击即可从 Bell 移除这一条任务。
- **只管提醒，不打断工作。** 不终止 Codex 里的实际任务，也不会把移除操作当作任务完成；同一项目之后的新任务照常显示。

### 新功能

- 主面板、展开的 Active 列表和菜单栏任务行均支持悬停移除。按钮平时隐藏，保留位置以避免文字跳动，并提供中英文说明和无障碍操作。

### 改进与修复

- 记住已移除的任务，防止后续同步、历史回放或重启让旧记录重新出现。
- 跳过该任务尚未播放的排队提醒，立即更新任务数量；不影响其他任务和音量试听。
- 升级时保留现有设置并兼容旧状态文件。v1.0.1 的完成误报修复、重试/错误分类以及 Recent 最多三条继续保留。

### 安装与已知限制

下载 `Codex-Bell-macOS-v1.0.2.zip`，退出旧版 Bell，解压并替换 `Codex Bell.app` 后重新打开。无需删除设置或重新配置 Codex。

- **× 不是 Codex 的停止按钮。** 如需终止实际任务，请在 Codex 中操作。目前没有恢复已移除记录的按钮；新任务仍会正常出现。
- 支持 **macOS 14 Sonoma 及以上、Apple silicon（arm64）**；没有 Intel 安装包。
- 此版本采用 hardened runtime + ad-hoc 签名，**不是 Apple Developer ID 签名，未经过 Apple 公证**。首次启动如被拦截，可尝试 Control 点击应用 →「打开」，或「系统设置 → 隐私与安全性 → 仍要打开」。也可以从源码构建。
- 状态识别依赖本机 Codex 的生命周期事件；未来格式变化可能需要集成更新。

## English

### Highlights

- **Clear stuck records yourself.** Hover over an Active task row to reveal a small ×, then click it to dismiss that turn from Bell.
- **Keep Codex work running.** Dismissal only stops Bell tracking and alerts. It does not cancel work or mark success, and new turns in the same project still appear.

### New features

- Hover dismissal is available in the main panel, expanded Active list, and menu-bar task row. The button stays hidden otherwise, reserves its space to avoid text movement, and includes bilingual help and an accessibility action.

### Improvements and bug fixes

- Dismissed records stay hidden across subsequent sync, historical replay, and restart.
- Pending announcements for the dismissed turn are skipped and task counts update immediately; other tasks and volume previews remain unaffected.
- Existing settings and older saved states remain compatible. The v1.0.1 false-completion fixes, retry/error classification, and three-row Recent list are preserved.

### Installation and known limitations

Download `Codex-Bell-macOS-v1.0.2.zip`. Quit the previous Bell instance, unzip and replace `Codex Bell.app`, then reopen it. Keep your existing settings and Codex integration.

- **× does not stop Codex.** Stop actual work in Codex if needed. There is currently no restore button for dismissed records; new turns still appear normally.
- Requires **macOS 14 Sonoma or later and Apple silicon (arm64)**. No Intel binary is included.
- Hardened runtime with an ad-hoc signature; **not Apple Developer ID signed and NOT NOTARIZED**. If blocked on first launch, try Control-click → Open, or System Settings → Privacy & Security → Open Anyway. Building from source is also supported.
- State detection depends on local Codex lifecycle events; future format changes may require an integration update.
