# Screenshot status / 截图状态

The v1.0.0 release intentionally ships without automated product screenshots. The verified local app contains retained task history, so an automated capture could expose private or internal task names.

v1.0.0 暂不附带自动截取的产品截图。已验证的本地应用保留了任务历史，自动截图可能泄露私人或内部任务名称。

Before adding screenshots, use synthetic task names and verify every visible pixel. Capture these views manually:

1. Main panel in Chinese with 1–4 synthetic active tasks.
2. Main panel in English with the same synthetic data.
3. Left and Right purple collapsed edge handles.
4. Settings → General with the Dock toggle off.
5. Expanded Active list with at least five synthetic tasks and no real project names.

添加截图前，请使用虚构任务名称并逐像素检查。需要人工补拍：中文主面板、英文主面板、左右紫色边缘把手、Dock 关闭的常规设置，以及使用虚构任务的多任务展开状态。
